# 用一次完整研究熟悉工作台

你可以从一份材料开始，也可以直接提出问题。下面是一条能留下来源、判断和报告的研究路线。

1. **收集材料。** 打开资料库的添加入口，导入公告、财报或网页选区。先检查预览，再确认写入。保留来源链接和发布时间。
2. **读摘要，核原文。** 在资料库选择材料，生成摘要；将关键事实与原文高亮对应。摘要不是原始证据，遇到重要数字回到材料核对。
3. **选择研究方式。** 到工作流选择“公司研究”“财报前瞻”“知识编译”等 Skill，附上材料并进入对话。例如：

   ```text
   研究这家公司的增长来源，区分销量、价格与产品结构。
   每个关键判断注明来源；再列出最有力的反方证据。
   ```

4. **对照观点。** 在多空观点里核对支持证据、反证和会改变判断的条件。回到原对话继续追问。
5. **留下报告。** 研究结果保留为 Markdown，在历史研究中阅读；有有效会话关联时，可以回到原对话继续。
6. **需要时做模拟。** 打开虚拟基金，创建基金和投研工位，说明初始资金、日期、研究风格与覆盖标的。让研究员读材料、记录观点，再用明确来源的价格推进纸面账本。

开启持续覆盖时，让助手确认频率与时区，并实际创建 DSH 计划任务。未创建成功之前，工位不会被视作已经开启。

自己的材料和配置不会随着安装包分发。建议先用公开资料熟悉流程，再决定哪些资料可以发送到所配置的模型。
