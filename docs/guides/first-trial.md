# 首次试用：安装检查与常见问题

当前发布包是 **v0.1.0 预览版**，适合小范围体验。自动检查通过不等于所有原生模型任务都已经验收。以下说明区分已发布的安装包与正在验证的修复，避免下载旧包后误以为已获得新补丁。

## 安装前先检查

1. 已安装 DeepSeek Harness，版本满足 `>=0.2.1-rc.1 <0.3.0`。
2. 在未安装插件前，先用你自己的模型配置完成一次普通 DSH 对话。若普通对话无法回复，先处理宿主的模型连接；插件不附带模型或密钥。
3. 从 [v0.1.0 发布页](https://github.com/DKKD13/dsh-finance/releases/tag/v0.1.0) 下载 `dsh-research-graph-0.1.0.tgz`。不要用页面里的 Source code 压缩包替代已构建的安装包。
4. 直接使用 npm 包安装到 DSH Web profile，无需解压：

   ```sh
   dsh plugin --profile web add /absolute/path/to/dsh-research-graph-0.1.0.tgz
   ```

   也可以先解压，再安装里面的 `package` 目录。它应包含 `package.json`、`cordis.patch.yml` 和 `dist/index.js`。安装路径必须是 DSH 所在电脑能访问的绝对路径。
5. 若选择目录安装，在 DSH 对话中发送：

   ```text
   请使用 plugin_manager 的 install_bundle，安装以下本地目录：
   <解压后的 package 目录绝对路径>
   ```

6. 等待插件管理器报告实际安装、激活结果，再打开侧栏的“金融”。请保留安装目录，不要安装后将它移入废纸篓。

从源码构建时，先运行 `npm ci && npm run build`，再用 `PACKAGE=$(npm pack --silent)` 取得实际包名，最后执行 `dsh plugin --profile web add "$PWD/$PACKAGE"`。完整的 npm 与本地包安装说明见 [npm 安装](npm-install.md)。使用预发布标签时可执行 `dsh plugin --profile web add deepseek-harness-finance-plugin@preview`，再用 `npm list deepseek-harness-finance-plugin` 核对实际安装版本。

本说明沿用宿主已有的插件安装方式；**发布流程仍未完成安装包在全新原生 DSH 中从安装到研究产物的完整验收**。若安装失败，请记录宿主给出的错误，不要通过关闭认证或修改数据库来绕过。

## 第一次使用怎么判断成功

- **查行情**：先查询一个有效代码，例如 `AAPL`。核对结果中的代码、来源和观察时间；网络或上游不可用时，不要将空值理解为零。已有报价也可能是历史观察值。
- **开始研究**：到“工作流”选择一个 Skill，说明研究对象、问题和资料时间，进入对话后检查草稿并发送。“进入对话”只准备草稿，不代表模型已经执行完毕。
- **继续阅读**：等待对话显示完成，打开实际生成的报告或文件；需要保存为研究记录时，在对话中明确提出。只有存在有效报告记录时，“历史研究”才会显示它。
- **查看资料**：从“资料库”添加一份获准使用的材料，检查预览后确认导入。阅读原文、来源链接和 AI 摘要时，重要数字仍以原文为准。
- **离开再回来**：刷新后重新打开同一会话、材料或已保存报告，检查内容仍在。若记录丢失，请停止重复提交并保留错误信息。

## 常见情况

| 现象 | 先检查什么 |
| --- | --- |
| 找不到“金融” | 插件管理器是否实际报告安装、激活成功；宿主版本是否兼容；安装目录是否仍存在。保留具体错误后再重试。 |
| 研究停在草稿、没有回答 | 是否已经发送；普通 DSH 对话是否也能使用当前模型；是否仍在运行或等待必要信息。 |
| 财务、持有人、预期等栏目为空 | 这些栏目依赖已导入的结构化资料，并非安装后自动获得的完整实时金融数据库。 |
| 行情查询失败 | 核对股票代码和网络，再按页面错误提示重试；公开来源的可用性不由插件保证。 |
| 模型说已保存，但列表找不到 | 打开它实际返回的产物或文件，核对保存是否成功及会话关联；不要仅凭回答中的“已完成”认定已持久化。 |
| 网页剪藏连接不上 | 剪藏扩展单独安装，本地接收服务默认关闭；还需显式配置服务、扩展 Origin 和 token。参见 [Clipper 说明](../../clipper-extension/README.md)，首次体验可先从资料库导入文件。 |

## 模拟基金与持续覆盖

虚拟基金使用纸面账本，不连接券商。历史净值对应已保存的价格与持仓输入，不代表真实投资业绩，也不会自动补出缺失的历史收益。

首次体验建议先关闭持续覆盖，手动完成一次研究和纸面记录。开启前，在 DSH 中确认频率、时区、计划任务的实际创建结果，以及后续停止或取消的可用入口；当前兼容宿主的暂停能力尚未完成完整验收。

## 更新、备份与反馈

更新前备份实际数据目录。默认是 `~/.dsh-research-graph/`，自定义配置以 `dataDir` 为准；先停止写操作再备份，不要直接编辑 `graph.json` 来修复界面问题。

遇到问题可在 [Issues](https://github.com/DKKD13/dsh-finance/issues) 提交：插件版本、DSH 版本、浏览器、操作步骤、预期结果、实际错误和经过检查的截图。不要上传模型密钥、token、私人研究材料或完整个人日志。
