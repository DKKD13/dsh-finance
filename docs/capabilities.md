# 能力与数据来源

DSH Finance 复用 Harness 的对话、模型和计划任务。插件负责研究资料、关系、金融计算和工作台界面。

| 能力 | 当前实现 | 需要什么 |
| --- | --- | --- |
| 研究工作流 | Skills 选择、上下文准备、原生对话草稿、报告关联 | 已配置的 DSH 模型和工作区 |
| 资料库 | 原文、版本、摘要、高亮、原始链接和关联洞见 | 导入材料；摘要由研究对话生成 |
| 网页与文件采集 | Clip JSON、RSS/Atom/OPML、PDF/DOCX/MD/TXT/HTML/CSV | 可处理的公开来源或自己的文件；先预览后确认导入 |
| 行情与图表 | Yahoo 报价、历史行情、比较、PNG/CSV 导出 | 网络和有效标的代码；上游服务不保证持续可用 |
| 财务、预期与持有人 | 按标的读取已存结构化字段 | 需要事先导入；不是完整实时数据库 |
| 财报日历、选股、预测市场 | 展示已导入字段和筛选结果 | 相应资料；示例模式使用合成数据 |
| 多空观点 | 对照支持与反驳证据、研究判断及审查记录 | 已存观点；AI 审查需要模型 |
| 估值与组合 | 本地 DCF、comps、敏感性、组合和 FX 计算 | 明确的假设、单位、币种与时点 |
| 虚拟基金 | 创建基金、角色与工位，保存研究记录，计算纸面持仓及净值快照 | 有来源的价格输入；不自动填充历史收益 |
| 持续研究 | 保存真实 DSH schedule 的关联，展示任务状态 | 必须由宿主实际创建计划；插件不附带独立常驻推理服务 |
| 预测复盘 | 记录预测，到期结算和确定性指标 | 显式截止时间与结果证据 |
| 知识图谱 | 搜索、关系、历史、差异、审计、Markdown 导出 | 本地 JSON store，无额外数据库 |

## 可选外部来源

- **SEC**：显式配置联系信息后请求公司代码和申报 facts。
- **OpenBB**：读取用户已有的 localhost 服务中的允许路由。
- **AlphaSift**：使用用户已有的 CLI；筛选调用禁用其 LLM 与后分析。
- **YouTube**：公开频道与无需 Cookie 的公开字幕，受上游可用性限制。

Daloopa、PitchBook、FactSet 等商业连接器未随本版本接入。模型推理使用你自己的 DSH 配置和额度。

## 发布截图说明

截图由本仓库构建出的真实 Client 组件生成，没有替换成概念界面。资料库使用公开来源的短节选与示例摘要；行情和基金使用明确的合成输入。基金数值由本地账本计算，仅用于演示，不是投资业绩。
